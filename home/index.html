8088 是唯一会动的入口。遥控台会下发底盘 / 手臂 / 路线 / VLA 指令；急停 = 页面红色按钮或 Esc，软件急停之后硬件急停仍要在手边。

8890 只有一个。视觉查看器占着 UDP 8890；跑推理时由 client 占用，抓取判定台会显示「画面中断」，这是正常的，不是坏了。

机器人只推一个 IP。远端 IP 指向 B70 时，Windows 上的 ta2-vision 就收不到流；要切回来得改机器人系统配置。

其余页面只读。观看、采集与判定页面不控制机器人；停机器人以遥控台急停、Ctrl+C client 和物理急停为准。
