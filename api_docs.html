接口文档 / 一键测试

编辑参数后点击「测试」，立即发送真实请求，不弹确认框。带 会动机器人 的卡片会启动动作。

动作返回 202 后自动查询至结束。停止与急停独立于查询；路线或全流程运行期间只接受急停。关闭页面或请求超时不会停止机器人。

所有调用都使用本机同源 /api/v1。模型只保留 RTC 版；指定单次抓取模型不改变网页选择。软件急停不能代替硬件急停。

错误码

HTTP 错误统一为 {"error":{"code":"…","message":"…"}}。动作执行失败在 HTTP 200 的记录中返回 status / error；failed、aborted 不代表查询失败。超时不会自动停止机器人。
